It's a to-do list built to look good and stay simple. Your tasks are saved in your own browser, so they're still there next time you open the page. No account is needed, and nothing is sent anywhere.

## What you can do with it

- Add a task with a title, an optional note and an optional due date.
- See your tasks sorted by due date. Tasks without a date go to the bottom.
- Spot overdue tasks at a glance: they get a red "overdue" label.
- Mark a task as done and watch it fade away.
