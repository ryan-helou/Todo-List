# To-Do List

A simple to-do list in the browser, with a retro pixel look and an animated space-style background.

This is a small personal project: a to-do list that looks nice and does the basics well. Your tasks are saved in your own browser, so they're still there next time you open the page. No account is needed, and nothing is sent anywhere.

## What you can do with it

- Add a task with a title, an optional note and an optional due date.
- See your tasks sorted by due date. Tasks without a date go to the bottom.
- Spot overdue tasks at a glance: they get a red "overdue" label.
- Mark a task as done and watch it fade away.
